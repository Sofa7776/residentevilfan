# Досье Resident Evil

Фанатский учебный сайт по истории вселенной Resident Evil.
ГУАП, дисциплина «Информатика», лабораторные работы №4–5.

## Разделы
Главная, Хронология, Части серии, Персонажи, Фильмы, Вирусы, Места, Организации.

## Структура проекта
```
index.html          — разметка страницы
css/style.css       — основное оформление
css/atmosphere.css  — атмосфера фильма ужасов (зерно, лента, неон)
js/images.js        — пути к изображениям
js/gallery.js       — какие фото показывать в каждом разделе
js/data.js          — тексты: части, персонажи, хронология, вирусы, фильмы
js/story.js         — подробные сюжеты по главам
js/main.js          — логика сайта
js/atmosphere.js    — фонарик, сбои экрана, звук
images/             — все изображения сайта
```

Resident Evil — товарный знак Capcom. Скриншоты и официальные изображения принадлежат Capcom, фанатские работы подписаны именами авторов.
